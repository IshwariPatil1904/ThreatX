Architecture

How ThreatX works

Quantum bits are generated via QKD simulation, messages are sealed with quantum-safe keys, and only the intended recipient can unlock them.

Key generation

Shared quantum keys are derived using the BB84 QKD protocol, ensuring true randomness at the source.

Encryption

Messages are encrypted with AES-256-GCM using keys exchanged through quantum-safe channels.

Secure transmission

Ciphertext travels over an encrypted connection with no feasibility of eavesdropping.

Decryption

The recipient uses the matching quantum key to recover the original plaintext message.

Future-proof security

Why ThreatX?

Getting started

How to use ThreatX

Getting started takes four simple steps.

Step 1 · Create account

Register a username and generate your personal key material.

Step 2 · Share key

Exchange your public key with a contact using secure QKD protocols.

Step 3 · Send message

Type your message — it is encrypted with the shared session key instantly.

Step 4 · Decrypt

The recipient uses the same key to decrypt and read the original message.
