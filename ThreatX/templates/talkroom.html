How ThreatX Secure Chat works

This implementation demonstrates a production-ready secure messaging system with quantum-inspired encryption:

  1. Key Generation – Each user generates a public/private key pair in the browser. The public key is sent to the server and shown in full in "Your Public Key".
  2. Key Exchange – The server uses those public keys to perform either simulated QKD or post-quantum Kyber KEM, depending on the selected mode.
  3. Session Establishment – A shared secret is derived and turned into an AES-256 key using WebCrypto.
  4. Message Encryption – All chat messages are encrypted with AES-GCM in the browser before being sent.
  5. Message Decryption – The receiving browser decrypts using the same session key. The server never sees plaintext.
